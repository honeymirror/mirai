# Mirai

A custom vibrant visual shader for Minecraft: Bedrock Edition

See more: [https://bambosan.github.io/mirai/](https://bambosan.github.io/mirai/)

## RenderDragonShaderLoader Variant

This fork contains an unofficial RenderDragonShaderLoader compatibility variant based on
Mirai 3.0.0. The `rdloader-variant` branch is itself a complete, directly importable shader
pack. Use GitHub's **Code > Download ZIP** and import the downloaded ZIP into
RenderDragonShaderLoader. No GitHub Release download is required.

The upstream source remains untouched on `main`. Variant details are documented in
[RDL-VARIANT.md](RDL-VARIANT.md).
